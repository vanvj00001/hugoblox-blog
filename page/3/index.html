二障不除，空说大乘

大善智师 发布于 2026-01-13 收录于 善智师法宝

前言

善智师开示"二障不除，空说大乘"之甚深义理。师者指出，众生学佛常犯之病在于不知除障，或知而不行。二障者，即烦恼障与所知障，此二障不除，纵然修习大乘法门，亦如说食数宝、终不得力。文中详析二障之来由、对治方法，强调唯有破除二障，方能真正趋入大乘法门。

师者更引《华严经》《深密经》等经典，阐释二障与菩提心之关系，令学人明白修行的根本在于断障显真。此开示为学佛者指出了除障用功的具体方向，极为切要。

昧佛义者，除苦何在？

大善智师 发布于 2026-01-14 收录于 善智师法宝

前言

善智师以"昧佛义者，除苦何在"为题，为学人开示不明佛义之害。师者指出，世间迷惑之人自称学佛，实则不解佛义，徒有修持形式而不得佛法真实利益。文中详析昧佛义之种种表现，如执文遣义、著相修行、分别计较等，皆是与解脱背道而驰之行。

师者更引《四十二章经》《金刚经》等经典，证明"迷惑者众、觉悟者寡"之末世因缘，告诫学人当亲近善智师、听闻正法、如理思惟。唯有真解佛义，方能真实离苦得乐。此开示令学人警醒，不可仅做表面佛学功夫，必须于心地真实用功。

了淫的开示

大善智师 发布于 2026-01-15 收录于 善智师法宝

前言

善智师针对"了淫"之修行要义进行开示。师者指出，淫乃轮回根本、生死之因，众生不知其害，沉溺其中不能自拔。文中从佛教戒律角度，详析淫欲之过患及其对修行之障碍，更引《楞严经》所言"淫为万恶之首"，阐明断淫乃出离三界之关键。

师者强调，学佛者当认清此害，勇断邪淫，方能保持清净心念，顺利趣入解脱正道。此开示为迷惑于淫欲之众生指明了出离苦海的要道，极为切要。

真得佛心印 人人皆弥勒

大善智师 发布于 2026-01-16 收录于 善智师法宝

前言

善智师开示"真得佛心印，人人皆弥勒"之妙义。师者指出，弥勒菩萨虽现菩萨相，实则与释迦牟尼佛同一法身，故经云"一切众生皆具佛性"。文中依《华严经》《法华经》等经典，阐明佛心印之真意——即众生本具之佛性真如，只要识得此心、印可此理，人人都能即身成佛、位齐弥勒。

师者更勉励学人，当知自心是佛、自性是佛，莫向他处求觅。唯有识得本心、明白佛印，方知人人本具如来智慧德相。此开示为执著他力救援之众生，指示了一条自力更生、即心是佛的光明大道。

识破错认光明耀

大善智师 发布于 2026-01-17 收录于 善智师法宝

前言

善智师以"识破错认光明耀"为题，开示学人当认清修行中之错认。师者指出，众生学佛常错认表相为实、执影子为我，不知光明本有、智慧自足。文中详析错认之种种表现，如认权威为真理、认形式为实质等，并指明破除错认之法。

师者强调，唯有识破错认，方能见得本有光明，否则纵然勤修苦行，亦如数他人宝、自己终不得力。此开示为迷失于名相文字之学人，指示了一条返照自心、识破虚妄的修行要道。

有开悟才有修行，有修行才有解脱

大善智师 发布于 2026-01-18 收录于 善智师法宝

前言

善智师开示"有开悟才有修行，有修行才有解脱"之真义。师者指出，世间人常倒以为先修行后开悟，不知无开悟之修行只是盲修瞎练。文中依《华严经》《楞严经》等经典，阐明先悟后修之重要，并详析开悟与修行、脱解之关系。

师者更强调，真正的开悟是识得自心、明白本有；真正的修行是念念相应、心心无住；真正的解脱是生死来去自由、烦恼永灭。此开示为学佛者指出了正确的修行次第，令学人不再迷惑于形式上的用功。
