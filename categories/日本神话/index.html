    琼琼杵尊：天孙降临与日本皇统的开端

    May 5, 2026
    日本神话
    琼琼杵尊, 天孙降临, 三神器, 日向国, 高千穗, 皇统始祖

    琼琼杵尊：天孙降临与日本皇统的开端#

    在日本神话的宏大叙事中，琼琼杵尊（ニニギノミコト）的降临，标志着天照大神的子孙正式接管苇原中国，开启了日本皇统的神圣谱系。作为天照大神的孙子，他不是以创世者的身份出现，而是以"天孙"的身份降临人间，将天界的秩序带到地上，建立了"万世一系"的神权政治基础。

    一、天照大神的决心：平定苇原中国#

    在平定苇原中国（出云国）的过程中，天照大神经历了多次挫折。她先派遣天穗日神（アメノホヒ）去接管国土，但天穗日神被大国主的威望所折服，反而成了他的家臣。接着派遣天次米命（アメノシタテル），结果同样被收服。

    天照大神意识到，苇原中国的局势远比想象中复杂。她召集高天原的众神，问道：“谁能为我平定苇原中国？”

    1.1 建御雷神的远征#

    最终，天照大神派遣了两位武神——建御雷神（タケミカヅチ）和经津主神（フツヌシ）。他们手持十拳剑，威风凛凛地降临出云。

    建御雷神找到大国主，厉声问道：“天照大神欲收回苇原中国，你意下如何？”

    大国主没有直接回答，而是说：“请让我问问我的儿子事代主神。”

    事代主神早已梦见天神降临，便说：“既然天照大神有意，我们理应让国。但条件是要为我们建造壮丽的神殿，并尊父亲为’大国主神’。”

    建御雷神同意了这些条件。大国主这才正式宣布让国，苇原中国正式纳入天照大神的统治之下。

    1.2 天孙降临的筹备#

    天照大神在平定苇原中国后，开始筹备"天孙降临"（テンソンコウリン）的盛大仪式。她决定派遣自己的孙子琼琼杵尊，带着三神器降临人间，建立永恒的皇统。

    琼琼杵尊是天照大神与素戋呜尊和解后，由天照大神之子天忍穗耳命（アメノオシホミミ）所生。据《古事记》记载，天照大神将三神器——八咫镜（ヤタノカガミ）、天丛云剑（アマノムラクモノツルギ，即草薙剑）、八尺琼勾玉（ヤサカニノマガタマ）——交给琼琼杵尊，叮嘱道：

    “此三神器，乃我高天原之宝物。你持此降临苇原中国，务必建立秩序，教化人民。皇统之绪，永世不绝。”

    二、天孙降临：从天而降的神之子#

    天孙降临是日本神话中最具政治象征意义的事件之一。它不仅是神话叙事的高潮，更是现实政治中"天皇神圣性"的理论基础。

    2.1 降临的地点：高千穗峰#

    据《日本书纪》记载，琼琼杵尊率领五伴绪（イツトモオ）等众神，从天而降，降临在日向国（今宫崎县）的高千穗峰（タカチホノミネ）。

    高千穗峰是一座火山，海拔1574米，位于雾岛连峰之中。这里被认为是"天"与"地"的交接点，是神与人相遇的圣地。至今，高千穗地区仍保留着许多与天孙降临相关的遗迹和传说。

    2.2 降临的仪式#

    琼琼杵尊的降临并非简单的"降落"，而是一场庄严的仪式。据《古事记》描述：

    1. 天浮桥：琼琼杵尊踏着"天浮桥"（アメノウキハシ）从天而降。这座桥连接着高天原与苇原中国，是神与人之间的通道。

    2. 天之岩户的象征：降临时，天照大神曾躲入天之岩户，导致世界陷入黑暗。琼琼杵尊的降临，象征着光明重新降临人间。

    3. 三神器的交接：天照大神将三神器交给琼琼杵尊时，郑重地说：“此镜即吾身，当以此镜为吾，祭拜之。“这确立了三神器作为皇统象征的神圣地位。

    2.3 五伴绪的随行#

    琼琼杵尊并非独自降临，他率领着五位重要的神明，合称"五伴绪”：

    • 天儿屋命（アメノコヤネ）：中臣氏的祖先，负责祭祀与占卜。
    • 太玉命（フトダマ）：忌部氏的祖先，负责神事与祭器。
    • 天钿女命（アメノウズメ）：猿女氏的祖先，天之岩户前跳舞的女神。
    • 伊斯许理度卖命（イシコリドメ）：镜作氏的祖先，制作八咫镜的工匠神。
    • 玉祖命（タマノオヤ）：玉作氏的祖先，制作八尺琼勾玉的工匠神。

    这五位神明不仅是琼琼杵尊的随从，更是后来日本朝廷中各氏族的祖先。天孙降临的故事，实际上是对各大氏族起源的神话解释。

    三、日向国的统治：建立地上秩序#

    琼琼杵尊降临后，并没有立即北上统治大和地区（今奈良县），而是在日向国（今九州地区）建立了根据地，开始了长达数百年的统治。

    3.1 高千穗宫的建立#

    琼琼杵尊在日向国的高千穗地区建立了"高千穗宫”（タカチホノミヤ），作为统治的中心。这座宫殿虽然简陋，但却是日本历史上第一座"皇宫"。

    在高千穗宫中，琼琼杵尊的主要工作包括：

    1. 祭祀天照大神：定期举行祭祀仪式，保持与高天原的联系。
    2. 教化人民：传授农业技术、医药知识、礼仪规范。
    3. 平定叛乱：镇压当地不服统治的恶神与豪族。
    4. 繁衍后代：生下海幸彦（ウミサチヒコ）与山幸彦（ヤマサチヒコ），为皇统延续血脉。

    3.2 与木花开耶姬的婚姻#

    琼琼杵尊在日向国期间，最重要的事件之一，是他与木花开耶姬（コノハナサクヤヒメ）的婚姻。

    木花开耶姬是山神大山津见神（オオヤマツミ）的女儿，以美貌著称。据《古事记》记载，琼琼杵尊一见到她，便爱慕不已，立即向大山津见神求婚。

    大山津见神大喜，将姐姐石长比卖（イワナガヒメ）和妹妹木花开耶姬一同许配给琼琼杵尊。但琼琼杵尊嫌弃石长比卖容貌丑陋，只留下了木花开耶姬。

    大山津见神愤怒地说：“石长比卖虽丑，却能保你长寿；木花开耶姬虽美，却会让你短命。你只选美貌，皇统将无法长久！”

    果然，琼琼杵尊在日向国统治数百年后，最终化为神灵升天，而他的子孙——神武天皇——则继续北上的征程。

    3.3 山幸彦与海幸姬的传说#

    琼琼杵尊与木花开耶姬生下了山幸彦（彦火火出见尊）与海幸彦（火阑降命）。兄弟俩的故事，是日本神话中著名的"山幸海幸"传说。

    海幸彦擅长钓鱼，山幸彦擅长打猎。一天，兄弟俩交换工具：海幸彦拿弓箭去打猎，山幸彦拿鱼钩去钓鱼。结果山幸彦不慎将鱼钩掉入海中，怎么也找不到。

    海幸彦大怒，要求山幸彦赔偿。山幸彦无奈，将自己的山神宫殿拆毁，打造了一把新鱼钩还给海幸彦。但海幸彦不满意，坚持要原来的鱼钩。

    山幸彦忧愁不已，来到海边哭泣。这时，盐土老翁（シオツチノオジ）出现，教他如何取回鱼钩，并征服海幸彦。山幸彦按照指示，潜入海底，找到了海神绵津见神（ワタツミ），最终迫使海幸彦臣服。

    这个故事不仅解释了海神与山神的分工，也暗示了日本皇统对海洋与陆地的双重统治。

    四、三神器的象征意义#

    琼琼杵尊从天照大神手中接过的三神器——八咫镜、天丛云剑、八尺琼勾玉——不仅是神话中的宝物，更是日本皇统的核心象征。

    4.1 八咫镜：智慧与诚实#

    八咫镜（ヤタノカガミ）是天照大神在天之岩户事件中，由石凝姥命（イシコリドメ）制作的神镜。当天照大神躲入岩户时，众神用这面镜子引诱她出来。

    镜子的象征意义在于"真实"（マコト）。镜子如实反映事物，不添加也不减少，象征着天皇应该具备的诚实与智慧。至今，日本皇室仍以八咫镜为最重要的神器，供奉在伊势神宫。

    4.2 天丛云剑：勇气与武力#

    天丛云剑（アマノムラクモノツルギ），又称草薙剑（クサナギノツルギ），是须佐之男命在出云国斩杀八岐大蛇时，从蛇尾中发现的神剑。

    大国主：从遭难王子到国土之神#

    在日本神话的宏大叙事中，大国主神（オオクニヌシ）的故事是一段从苦难到荣耀的传奇。他不是以创世者的姿态登场，而是以一位在兄弟迫害中挣扎求生的王子身份出现，最终成为统治苇原中国（出云国）的国土之神。他的神话充满了兄弟阋墙的阴谋、神奇动物的救助、与海神的交易，以及最终将国土让渡给天照大神后裔的"让国"壮举。大国主的故事，是日本神话中人间色彩最浓重、最富有人情味的一章。

    一、出生与迫害：八十神嫉妒的兄弟#

    大国主神原名大己贵神（オオナムチ），是须佐之男命之子。据《古事记》记载，须佐之男命从高天原被放逐后，降临出云国，与当地神女结婚，生下了许多子女。其中，大己贵神与八十个兄弟神（八十神）同为须佐之男的后裔，但大己贵神因其特殊的出生和气质，成为了八十神嫉妒的对象。

    八十神对大己贵神的嫉妒并非无缘无故。在神话中，大己贵神被描绘为一位拥有特殊能力和魅力的神，而八十神则是平庸且善妒的群体。他们视大己贵神为眼中钉，多次设计谋害他。

    1.1 第一次谋杀：烫死的阴谋#

    八十神的第一次谋杀计划发生在因幡之国（今鸟取县）。他们假装与大己贵神和解，提议一起去见因幡的公主八上比卖（ヤガミヒメ）。在路上，八十神用石头砸死了一只兔子，然后剥下兔皮，让大己贵神去捡。大己贵神不知是计，赤脚踩在锋利的石头上，痛苦不堪。

    然而，这个阴谋并未得逞。大己贵神在兔子的帮助下（后文详述），不仅活了下来，还得知了八十神的真正意图。

    1.2 第二次谋杀：赤猪陷阱#

    八十神见一计不成，又生一计。他们制作了一只巨大的赤猪（红土塑成的假猪），里面填满石头，外表涂成红色，看起来像一头活蹦乱跳的野猪。他们欺骗大己贵神说：“那山上有头肥美的赤猪，我们去追捕它吧！”

    大己贵神信以为真，追着赤猪跑。八十神突然从后面推倒大己贵神，将他压在赤猪下面。大己贵神被沉重的石头压得动弹不得，几乎窒息而死。幸亏他的母亲刺国若比卖（サシクニワカヒメ）及时赶到，用神力救了他。

    1.3 第三次谋杀：火刑之难#

    最残忍的一次谋杀发生在须佐之男的宫殿。八十神将大己贵神骗进一间封闭的大屋，里面堆满了锋利的岩石和燃烧的木炭。他们从外面锁上门，点燃木炭，企图将大己贵神烧死。

    大己贵神在火海中痛苦挣扎，几乎丧命。但就在他即将昏厥之际，一只老鼠突然出现，在他面前挖开一条地道。老鼠对他说：“里面有三条路，快进去！“大己贵神爬进地道，老鼠用泥土堵住入口，八十神找不到他，以为他已葬身火海。

    这些迫害的故事，展现了古代日本社会兄弟争权、骨肉相残的残酷现实。大己贵神一次次死里逃生，不仅靠运气，更靠动物们的帮助——兔子、老鼠、以及后来的蚰蜒（蜈蚣）和蜜蜂，这些动物成为了他生命中的守护者。

    二、因幡之白兔：日本最古老的寓言#

    大国主神话中最著名的插曲，莫过于"因幡之白兔”（因幡の白兎）的故事。这个故事被收录在《古事记》和《日本书纪》中，是日本最古老的动物寓言之一，充满了道德寓意和神话色彩。

    2.1 白兔的遭遇#

    故事发生在因幡海岸。一只白兔（其实是神，化身为兔）想要从隐歧岛（オキノシマ）渡海到因幡国。但它没有船，于是想出一个诡计。它骗鲨鱼（或鳄鱼，古日语中"ワニ"可指两者）说：“我们来比赛吧，看谁绕岛一圈的距离更长。你把同伴们排成一列，我从它们背上跳过去。”

    鲨鱼们信以为真，排成一列长龙。白兔一跳一跳地踩着鲨鱼背前进，快要到达岸边时，它得意忘形，嘲笑道：“你们上当了！“话音刚落，最后一只鲨鱼愤怒地咬住白兔，剥光了它的皮。

    白兔赤身裸体，痛苦不堪，躺在海岸上奄奄一息。

    2.2 大国主的救治#

    此时，八十神也来到了因幡，想要向八上比卖求婚。他们看到岸边的白兔，便假惺惺地说：“我们用海水洗你的身体，再用风吹干，这样你的皮就会长出来。“白兔照做了，结果海水让伤口更痛，风一吹，皮肉撕裂，白兔痛得死去活来。

    接着，大己贵神（大国主）路过此地。白兔向他求救：“求你救救我！“大己贵神温柔地说：“你到河边的淡水里洗净身体，然后取河边的蒲黄花粉，撒在花粉堆里打滚。这样你的皮就会重新长出来。”

    白兔照做，果然皮肉再生，恢复了原状。为了报恩，白兔预言道：“八十神虽然人多势众，但他们得不到八上比卖。只有你，大己贵神，才能得到她的芳心。”

    果然，当八十神向八上比卖求婚时，她毅然选择了大己贵神。八十神恼羞成怒，再次密谋杀害大己贵神。

    2.3 寓言的深层含义#

    “因幡之白兔"的故事绝非简单的动物寓言，它蕴含了多层象征意义：

    1. 欺诈与报应：白兔用诡计欺骗鲨鱼，最终自食其果。这反映了日本文化中对"诚”（マコト）的重视——诚信是神与人共同的道德准则。

    2. 慈悲与智慧：大国主用正确的方法救治白兔，展现了他的仁慈与智慧。这与八十神的伪善形成鲜明对比。

    3. 弱者的力量：白兔虽弱小，却能预言未来，影响神的命运。这暗示了弱势群体也能通过智慧改变局面。

    4. 自然崇拜：故事中的动物、海洋、河流、花粉，都是自然的一部分。日本神话深深植根于对自然的观察与敬畏。

    这个故事后来成为日本文学中的经典意象，出现在《源氏物语》《平家物语》等作品中，甚至成为现代动漫和游戏的灵感来源。

    三、与少彦名的合作：建国与医药之神#

    在大己贵神逃过八十神的追杀后，他开始了治理苇原中国（出云国）的伟业。但这项任务太过艰巨，他一个人无法完成。于是，一位神奇的小神出现了——少彦名神（スクナヒコナ）。

    3.1 少彦名的降临#

    少彦名神是高御产巢日神（タカミムスビ）的儿子，从指缝间化身为小虫降世。他身高只有一寸（约3厘米），但却拥有超凡的神力。当大己贵神在出云海岸遇到这位小神时，起初并不相信他的能力。

    少彦名神说道：“我是高御产巢日神的儿子，奉父命来助你建国。“大己贵神这才意识到，这位小神是天神的使者。

    3.2 共同治理苇原中国#

    大己贵神与少彦名神结为搭档，开始了治理苇原中国的伟大工程。他们的工作主要包括：

    1. 制定律法：建立社会秩序，规范人与人之间的关系。

    2. 开垦土地：将荒野变为良田，教导人民耕种。

    3. 医药发明：少彦名神精通医药，发明了治疗疾病的草药和方法。他因此被尊为医药之神，后世的温泉、药草疗法都与他有关。

    4. 道路建设：修建连接各地的道路，促进贸易与文化交流。

    5. 驱除灾祸：消除国土上的恶神、毒虫、猛兽，保障人民安全。

    3.3 少彦名的离去#

    当苇原中国的治理初具规模时，少彦名神突然说：“我的任务已完成，该回天上了。“说完，他乘着一艘芦苇船，消失在云海之中。

    大己贵神独自继续治理出云国，但他始终铭记少彦名的教诲。少彦名虽然离去，但他的医药知识和治国智慧，深深烙印在出云文化中。

    3.4 医学神话的文化意义#

    大国主与少彦名合作治国的故事，反映了古代日本对医学和农业的重视。少彦名作为医药之神，与中国的神农氏、希腊的阿斯克勒庇俄斯有相似之处。这暗示了古代东亚文化在医药领域的交流。

    同时，大国主作为"国土之神”（クニヌシ），其职责是管理与秩序，而少彦名则代表技术与创新。两者的结合，象征着日本神话中"传统与革新"的平衡。

    四、根之国访问：与须佐之男的对话#

    在治理苇原中国的过程中，大国主遇到了一件棘手的事——他的儿子事代主神（コトシロヌシ）梦见：“天照大神将派她的儿子下来统治苇原中国，你应该去根之国（黄泉国）问问你父亲须佐之男的意见。”

    4.1 进入根之国#

    大国主带着恐惧与敬畏，踏上了前往根之国的旅程。根之国是死者的世界，位于地底深处，充满黑暗与恐怖。但大国主别无选择，只能前进。

    在根之国的宫殿里，须佐之男正坐在宝座上。这位曾经狂暴的海神，如今已成为地底世界的统治者。他看到儿子到来，冷冷地问：“你来做什么？”

    大国主恭敬地回答：“天照大神欲派其子统治苇原中国，我想听听您的意见。”

    4.2 须佐之男的预言#

    须佐之男沉默片刻，缓缓说道：“苇原中国本是我所统治的土地，如今由你继承。但天照大神的权威不可违背。你可以将国土让给她，条件是她必须为你建造壮丽的神殿，并尊你为’大国主神’。”
