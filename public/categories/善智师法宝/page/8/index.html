佛在心，故向外驰求者终无是处

前言

本文开篇即点明"佛在心"这一核心命题，以此破斥学人向外攀求的迷执。师父引用《华严经》“心佛众生三无差别"之义，阐明一切众生本具如来智慧德相，只因妄想执著不能证得。文章以大量经论为据，开示向内求法、离心取法的道理，指出外求者终入歧途，唯有内观自心方能见性成佛。

正因值正缘方有真修行

前言

本文以"正因正缘"为题，阐明修行成就的因缘法则。师父指出，学人所以难得真修行，皆因缺乏正因正缘——或以生灭心攀求、或以名利心学法、或以执著心修持，种种偏差皆因背离因缘法则。文章通过《华严经》因缘法的阐述，教导学人当以清净心为正因、以善知识为正缘，因缘和合，方能感应道交、修行成就。

迷患四病的末世学佛

前言

本文针对末世学佛人易犯的四种偏差——我法二执、文字戏论、邪知邪见、狂禅空洞——进行深入剖析。师父引用《圆觉经》“末世众生希望成道，无令求悟，唯益多闻，增长我见"的警示，详细阐释四病的具体表现及其危害，并开示对治之法。文章劝诫学人当以谦下之心、离相之智，破除四病，方入正修行路。

心中执我非觉体 实相真我觉体呈

前言

本文从"我"与"觉"的区分入手，阐明学人当识破分别我执、显现真实觉性。师父引用《圆觉经》“云何我相？谓诸众生心所证者"的经文，揭示我相的本质是众生自心所取的一种虚妄执相，非真实我。文章指出，唯有放下我相，方能照见本自具足的灵觉真心——此心不生不灭、恒常不变、光明清净，是名法身真我。

不识本心 学法无益 在於见不了性

前言

善智师阐释"不识本心，学法无益，在于见不了性"之义。师者指出，学佛之根本在于识得本心、见自本性，若不识本心，纵然读经诵咒、持斋守戒，终是煮沙成饭、徒劳无功。文中依达摩祖师及六祖慧能大师之教言，开示如何识心见性、灭度业障。

师者更强调，识本心是学佛的唯一目的，见本性是修行的最终目标。此开示为迷于外求之学人敲响警钟，令其回归自心用功。

明佛意 佛子真

前言

本文以"明佛意"为中心，阐明学佛人当深入经藏、明了如来真实义的重要性。师父指出，多数学人所以学法无益，皆因不解佛意，执著文字相而生种种妄想分别。文章通过《法华经》等经典教义，揭示佛出世之本怀——开示悟入佛之知见，使一切众生皆能识得本心、明心见性，是名真佛子。

心应佛意法印心 不识本心颠倒亲 心障不除益难真

前言

本文开篇即提出"心应佛意、法印于心"这一修行核心命题，以此破斥学人迷执外相、忘却本心的偏差。师父引用《华严经》“一切众生皆具足如来智慧德相"的经文，阐明学人当以佛知见为准则，反照自心，识得本心具足一切功德。文章强调，心障不除，则增益难成；唯有净除心垢，方能真实受益。

浅谈般若与业力

前言

本文从般若智慧与业力对治两个方面，阐述学佛修行中的核心问题。师父指出，般若为成佛之母，能照破无明、度脱烦恼；而业力则是众生轮回之因，障碍修行、招感苦报。文章通过《华严经》《入楞伽经》等经典，阐明修行人当以般若智慧观照业力本质，知其无自性，方能转恶为善、转染成净，最终究竟解脱。

三十七助道品共分七科

前言

本文系统讲解佛教三十七助道品的内涵及其在修行中的重要作用。师父将三十七品分七科论述：四念处、四正勤、四如意足、五根、五力、七觉支、八正道，每一品皆为修行人趣向解脱的助道资粮。文章详细阐释每一科的具体内容与修习方法，使学人明白正修行路当于三十七道品如实了知，如实修习。

戒淫文

前言

本文以戒淫为主题，从佛教戒律与修心两个层面深入阐述邪淫的危害。师父援引《楞严经》中关于淫欲障道的教言，结合现实案例，揭示淫欲如何蚕食修行人的道心，使其远离清净、堕入轮回。文章强调戒淫不仅是外在行为的约束，更是内心贪欲的彻底断除，唯有如此方能保持定力、趋向解脱。
